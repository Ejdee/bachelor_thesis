# Do NOT install torch via pip install -r requirements.txt for the torch line;

#
#   pip install 'git+https://github.com/facebookresearch/detectron2.git'
#
# Make sure torch is already installed before running the command above.
# If you get a CUDA version mismatch error, this is almost always the fix.
# ------------------------------------------------------------------------------
# detectron2  ← install from source, see above
